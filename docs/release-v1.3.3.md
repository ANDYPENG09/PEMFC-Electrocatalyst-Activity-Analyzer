Download `index.html` from Assets and open it in a browser to work offline.

- Multi-cycle CV data default to cycle 2 for ECSA. Change the selection beside the CV input to recalculate and redraw.
- AfterMath files use the recorded segment boundaries when available. For two segments per cycle, cycle 2 uses segments 3 and 4, and its anodic segment supplies the H-upd integral.
- The original trace remains available. The cycle number is included in the single-sample CSV and saved workbench analysis.
