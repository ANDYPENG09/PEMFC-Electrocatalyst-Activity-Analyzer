Choose **Appearance** next to the language switcher. The four themes share the same analysis workspace and work offline. Your browser remembers the selected appearance.

- **Clear Glass** uses a floating navigation bar, translucent surfaces, and bright glass edges.
- **Blue Glass** retains the blue-purple theme with desktop sidebar navigation.
- **Classic** uses a plain white workspace on a light gray background.
- **Editorial Grid** uses large type, fine rules, and a warm paper palette.

Download `index.html` from Assets and open it in a browser to work offline.
